# Prism 分析规范 Skill 包

购买 Prism AIGC 即赠送这套分析规范。它是软件内置规范的同源整理版：**去掉了内部项目名、岗位代号和流程编号**，保留可独立执行的规则、判断标准和输出格式。

## 包含什么

| 模块 | 内容 |
|---|---|
| 剧本分析 | 拆集、类型判定、风格锚定、特殊场面标记、剧本体检 |
| 角色分析 | 人物识别、性格与动机、人物关系、外形与服饰要点 |
| 场景与道具 | 场景识别、空间结构、道具清单与复用判断 |
| 资产筹备 | 人物妆造、服饰设计、场景美术、道具四卷；按仙侠 / 未来科幻 / 民国 / 古装 / 现代都市五类题材分册 |
| 分镜 | 景别、角度、构图、光影与色调、动势、转场、运镜术语、情绪表演、特殊场面处理 |
| 提示词组装 | 单帧提示词结构、风格锚、负面锚、参考图写法 |
| 关键帧需求 | 关键帧类型、移动帧链、人物位置图、参考素材要求 |
| 海报封面 | 海报决策流程、构图与光影手法、质感路线、编辑模型用法 |

共约 50 份文档，按模块分目录存放。

## 怎么用

- 每份文档都可以单独作为系统提示词使用；
- 也可以把同一模块的几份文档一起投喂给支持长上下文的模型；
- 文档里的规则是独立的，不依赖 Prism AIGC 软件本身；
- 建议配一个能力较强的文本模型，并按文档里的输出格式要求约束返回。

## 说明

- Skill 包是**可读的 Markdown 文档**，不是软件的一部分；
- 软件内置的规范会随版本更新，Skill 包按版本同步发放；
- 规范是方法论文档，不包含任何模型 Key、账号或第三方服务凭证。
