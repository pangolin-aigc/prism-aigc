# 快速开始

## 1. 解压

把收到的 Windows 绿色版压缩包解压到一个**有写权限**的目录，例如：

```
D:\PrismAIGC\
```

不要放在系统盘根目录或 `Program Files` 下，避免权限问题。

## 2. 启动

双击 `启动 Prism AIGC`（或同目录下的启动程序）。

- 启动后浏览器会自动打开工作台
- 如果没有自动打开，手动访问启动窗口提示的地址（默认 `http://127.0.0.1:8811`）
- 第一次启动时 Windows 可能弹出防火墙提示，选择「允许」

数据都在程序目录下的 `data/`：

```
data/
├─ weilai.db     项目、剧本、资产、分镜、生成记录
└─ media/        图片、视频、关键帧
```

备份 = 拷贝整个 `data/` 目录。

## 3. 配置模型渠道

顶栏 →「模型渠道」→「添加渠道」：

| 字段 | 说明 |
|---|---|
| 名称 | 自己起个名字，会显示在画布的模型下拉里 |
| Base URL | OpenAI 兼容地址，例如 `https://api.deepseek.com/v1` |
| API Key | 只保存在本机数据库，列表只显示掩码 |
| 模型名 | 例如 `deepseek-chat` |
| 类型 | 文本 / 图片 / 视频 |
| 启用 | 打开 |

保存后点「测试」，通过即可。

**图片渠道**：支持 ModelScope、阿里云百炼，以及 OpenAI 兼容的图片接口。

**视频渠道**：支持阿里云百炼 Wan2.2、Agnes Video。视频渠道需要填写「媒体公网地址」——本地素材要拼成公网 URL，模型才能取到参考图。按渠道说明填写即可。

> 不配渠道也能用：系统会走「演示规则」把流程跑通，但产出是示例级；配好渠道后才走真模型。

## 4. 新建项目

项目列表 →「新增」：

1. 填项目名称、所属团队（选填）
2. 导入剧本：拖入 `docx / txt / md`，或直接粘贴
3. 选画面比例：9:16（竖屏）/ 16:9（横屏）
4. 点「创建并开始分析」

剧本里建议包含：

- 「第1集 / 第2集」之类的集号
- 「场景：xxx」
- 「人名：台词」格式的对话

创建后系统会自动拆集、分析风格、提取人物关系和项目简介。

## 5. 按页推进

```
剧本管理 → 资产 → 分镜 → 视频画布 → 视频管理 → 海报
```

- **剧本管理**：看分析风格、人物简介、人物关系；可重新分析
- **资产**：逐类生成角色 / 服饰 / 定妆照 / 群像 / 场景 / 道具
- **分镜**：自动分段，检查每段镜头表与提示词；可用 Agent 改
- **视频画布**：把素材和关键帧连到视频节点，逐段生成
- **视频管理**：选版本、合成成片、截关键帧
- **海报**：用海报 Agent 出多版本封面

## 6. 更新

更新时只替换程序目录，**保留 `data/`**。

群内和网盘会同步新版本；也可以在仓库的 `CHANGELOG.md` 查看更新内容。

## 常见问题

**启动后浏览器打不开？**
先看启动窗口有没有报错；确认端口没有被其他程序占用。

**换电脑怎么迁移？**
把整个 `data/` 目录拷到新电脑的程序目录下即可。

**素材太大怎么办？**
`data/media/` 里是原图原视频，可以按项目定期清理；清理前先备份。
