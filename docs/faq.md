# 常见问题

## 购买与授权

**Q：多少钱？**
A：¥199，一次性买断。

**Q：后续更新收费吗？**
A：终身免费更新。

**Q：一份授权可以装几台电脑？**
A：授权跟随购买者本人使用，具体以购买时的说明为准；换电脑把 `data/` 拷贝过去即可，团队多人使用请先咨询。

**Q：可以商用吗？**
A：可以用于你自己的商业项目。模型服务条款和生成内容的合规性由使用者自行负责。

**Q：可以开发票吗？**
A：购买前先咨询，以实际可开具的票据类型为准。

**Q：支持退款吗？**
A：软件属于虚拟商品，退款政策以购买时的说明为准；购买前可以先看截图和演示，有疑问先咨询。

## 软件与数据

**Q：需要装 Python / Node 吗？**
A：不需要。Windows 绿色版解压即用。

**Q：我的剧本会上传到你们的服务器吗？**
A：不会。剧本、素材、生成记录都保存在本机；生成时只发送给你自己配置的模型服务商。

**Q：API Key 存在哪里？**
A：本机数据库 `data/weilai.db`，界面只显示掩码，不会上传。

**Q：断网还能用吗？**
A：项目管理和本地编辑可以；生成图片/视频/文本需要联网。

**Q：数据怎么备份？**
A：拷贝整个 `data/` 目录即可，项目和素材都在里面。

**Q：卸载会删数据吗？**
A：不会。删除程序目录前，先把 `data/` 备份或移走。

## 模型与生成

**Q：可以用哪些模型？**
A：文本走 OpenAI 兼容接口；图片支持 ModelScope、阿里云百炼及兼容接口；视频支持百炼 Wan2.2、Agnes Video。

**Q：模型费用怎么算？**
A：由对应模型服务商按量计费，直接从你的账号扣，不经过我们。

**Q：生成失败怎么办？**
A：先看界面报错和模型渠道的「测试」结果；常见原因是 Key 无效、余额不足、参考图太大或渠道限流。

**Q：可以接本地模型吗？**
A：文本和图片只要兼容 OpenAI 协议就可以尝试；视频渠道目前以云端模型为主。

## Skill 包

**Q：赠送的 Skill 包是什么？**
A：一套整理过的分析规范文档，覆盖剧本分析、角色/场景/道具、资产筹备、分镜、提示词组装、关键帧、海报。可以配合你自己的 AI 工具使用。

**Q：可以分享或转卖吗？**
A：不可以。仅限购买者本人使用，禁止转售、公开或二次分发。

## 系统

**Q：支持 Mac 吗？**
A：目前只有 Windows 10/11 64 位；Mac 版在开发中。

**Q：需要什么配置？**
A：建议 8GB 以上内存；素材和视频会占磁盘，建议预留充足空间。
